# Rāga Reference Guide — राग संदर्भ

A comprehensive reference for all Rāgas supported by Vedic Voice Studio.

---

## What is a Rāga?

A **Rāga** (राग) is the melodic framework of Indian Classical Music. It is not merely a scale — it is a complete melodic personality defined by:

- **Āroh** (आरोह) — Ascending note sequence
- **Avaroh** (अवरोह) — Descending note sequence
- **Vādī** (वादी) — The most prominent note (king note)
- **Samvādī** (संवादी) — The second most important note (minister note)
- **Pakad** (पकड़) — Characteristic catch-phrase
- **Samay** (समय) — Time of performance
- **Rasa** (रस) — Emotional sentiment

### The Seven Svaras (Notes)

| Svara | Abbreviation | Western Equivalent | Solfège |
|-------|-------------|-------------------|---------|
| षड्ज (Ṣaḍja) | **Sa** | C | Do |
| ऋषभ (Ṛṣabha) | **Re** | D | Re |
| गान्धार (Gāndhāra) | **Ga** | E | Mi |
| मध्यम (Madhyama) | **Ma** | F | Fa |
| पञ्चम (Pañcama) | **Pa** | G | Sol |
| धैवत (Dhaivata) | **Dha** | A | La |
| निषाद (Niṣāda) | **Ni** | B | Ti |

Modifiers: **komal** (♭ flat) = lowercase · **tīvra** (♯ sharp) = uppercase with `'`

## Supported Rāgas

### 1. Bhairavī · भैरवी
| Property | Value |
|----------|-------|
| **Thāṭ** | Bhairavī |
| **Samay** | All times (especially morning) |
| **Rasa** | Bhakti (devotion), Karuṇā (compassion) |
| **Āroh** | Sa re ga Ma Pa dha ni Sā |
| **Avaroh** | Sā ni dha Pa Ma ga re Sa |
| **Vādī** | Ma |
| **Samvādī** | Sa |
| **Pakad** | dha ni Sa, ga Ma ga re Sa |
| **Usage** | Bhajans, concluding pieces, devotional compositions |
| **Note** | Uses all komal (flat) svaras except Sa and Pa |

### 2. Yaman · यमन
| Property | Value |
|----------|-------|
| **Thāṭ** | Kalyāṇ |
| **Samay** | First prahar of night (6–9 PM) |
| **Rasa** | Śṛṅgāra (romantic), Bhakti (devotional) |
| **Āroh** | Ṇi Re Ga Ma' Pa Dha Ni Sā |
| **Avaroh** | Sā Ni Dha Pa Ma' Ga Re Sa |
| **Vādī** | Ga |
| **Samvādī** | Ni |
| **Pakad** | Ṇi Re Ga Re, Pa Ma' Ga Re Sa |
| **Usage** | Evening concerts, romantic compositions |
| **Note** | Uses tīvra (sharp) Ma exclusively |

### 3. Bhairav · भैरव
| Property | Value |
|----------|-------|
| **Thāṭ** | Bhairav |
| **Samay** | Early morning (4–7 AM) |
| **Rasa** | Śānta (peace), Vīra (heroic), Bhakti (devotion) |
| **Āroh** | Sa re Ga Ma Pa dha Ni Sā |
| **Avaroh** | Sā Ni dha Pa Ma Ga re Sa |
| **Vādī** | Dha |
| **Samvādī** | Re |
| **Pakad** | Ga Ma dha Ni dha Pa, Ma Ga re Sa |
| **Usage** | Morning prayers, Shiva devotional music |
| **Note** | Komal Re and Dha give the distinctive "morning" sound |

### 4. Mālkauṃs · मालकौंस
| Property | Value |
|----------|-------|
| **Thāṭ** | Bhairavī |
| **Samay** | Late night (12–3 AM) |
| **Rasa** | Śānta (peace), Karuṇā (pathos) |
| **Āroh** | Sa ga Ma dha ni Sā |
| **Avaroh** | Sā ni dha Ma ga Sa |
| **Vādī** | Ma |
| **Samvādī** | Sa |
| **Pakad** | Ma dha ni dha Ma, ga Ma ga Sa |
| **Usage** | Deep meditative compositions, late-night recitals |
| **Note** | Pentatonic rāga (5 notes). No Re or Pa. All komal svaras. |

### 5. Darbārī Kānaḍā · दरबारी कानडा
| Property | Value |
|----------|-------|
| **Thāṭ** | Āsāvarī |
| **Samay** | Late night (9 PM–12 AM) |
| **Rasa** | Gambhīra (grandeur), Vīra (heroic) |
| **Āroh** | Sa Re ga Ma Pa dha ni Sā |
| **Avaroh** | Sā dha ni Pa Ma ga, Ma Re Sa |
| **Vādī** | Re |
| **Samvādī** | Pa |
| **Pakad** | Ma Re Sa, Re ga Ma Re Sa |
| **Usage** | Royal court music, grand compositions |
| **Note** | Characteristic andolan (oscillation) on ga and dha |

### 6. Toḍī · तोडी
| Property | Value |
|----------|-------|
| **Thāṭ** | Toḍī |
| **Samay** | Late morning (9 AM–12 PM) |
| **Rasa** | Karuṇā (pathos), Viraha (longing) |
| **Āroh** | Sa re ga Ma' dha ni Sā |
| **Avaroh** | Sā ni dha Pa Ma' ga re Sa |
| **Vādī** | Dha |
| **Samvādī** | ga |
| **Pakad** | dha ni dha Pa, Ma' ga re Sa |
| **Usage** | Expressive, emotion-laden compositions |
| **Note** | Komal Re, Ga, Dha with tīvra Ma |

### 7. Kāfī · काफ़ी
| Property | Value |
|----------|-------|
| **Thāṭ** | Kāfī |
| **Samay** | Late night to midnight |
| **Rasa** | Śṛṅgāra (romantic), Bhakti |
| **Āroh** | Sa Re ga Ma Pa Dha ni Sā |
| **Avaroh** | Sā ni Dha Pa Ma ga Re Sa |
| **Vādī** | Pa |
| **Samvādī** | Sa |
| **Pakad** | Ma Pa Dha, Ma ga Re, Sa Re ga |
| **Usage** | Light classical, thumri, seasonal songs |
| **Note** | Komal Ga and Ni; semi-classical feel |

### 8. Bāgeśrī · बागेश्री
| Property | Value |
|----------|-------|
| **Thāṭ** | Kāfī |
| **Samay** | Second prahar of night (9 PM–12 AM) |
| **Rasa** | Śṛṅgāra (romantic), Karuṇā (tender) |
| **Āroh** | Sa ga Ma Dha ni Sā |
| **Avaroh** | Sā ni Dha Pa, Ma ga Re Sa |
| **Vādī** | Ma |
| **Samvādī** | Sa |
| **Pakad** | Ma Dha ni Dha, Ma ga Re Sa |
| **Usage** | Night concerts, romantic compositions |
| **Note** | Re is avoided in āroh; komal Ga and Ni |

### 9. Desh · देश
| Property | Value |
|----------|-------|
| **Thāṭ** | Khamāj |
| **Samay** | Second prahar of night (monsoon) |
| **Rasa** | Vātsalya (affection), Deśabhakti (patriotism) |
| **Āroh** | Sa Re Ma Pa Ni Sā |
| **Avaroh** | Sā ni Dha Pa Ma Ga Re Sa |
| **Vādī** | Re |
| **Samvādī** | Pa |
| **Pakad** | Re Ma Pa, ni Dha Pa Ma Ga Re Sa |
| **Usage** | Patriotic songs, monsoon music, light classical |
| **Note** | Śuddha Ni in āroh, komal Ni in avaroh |

### 10. Khamāj · खमाज
| Property | Value |
|----------|-------|
| **Thāṭ** | Khamāj |
| **Samay** | Second prahar of night |
| **Rasa** | Śṛṅgāra (romantic), Hāsya (playful) |
| **Āroh** | Sa Ga Ma Pa Dha Ni Sā |
| **Avaroh** | Sā ni Dha Pa Ma Ga Re Sa |
| **Vādī** | Ga |
| **Samvādī** | Ni |
| **Pakad** | Ga Ma Pa Dha Pa, Ma Ga Re Sa |
| **Usage** | Thumri, dadra, light romantic compositions |
| **Note** | Śuddha Ni in āroh, komal ni in avaroh |
